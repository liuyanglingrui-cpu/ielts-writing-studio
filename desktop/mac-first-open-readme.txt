IELTS Writing Studio（Apple 芯片版）首次打开
================================================

1. 双击 ZIP 文件完成解压。
2. 请保留“首次打开我.command”和“IELTS Writing Studio.app”在同一文件夹。
3. 按住 Control 键点击“首次打开我.command”，选择“打开”。
4. 如果系统再次询问，请继续选择“打开”。脚本会完成本机签名并自动启动应用。
5. 完成一次以后，直接双击 IELTS Writing Studio.app 即可。

如果没有看到“打开”按钮：
打开“系统设置”→“隐私与安全性”，向下滚动，在安全性区域选择“仍要打开”。

这个脚本只处理同一文件夹中的 IELTS Writing Studio.app，不会修改系统的全局安全设置。
